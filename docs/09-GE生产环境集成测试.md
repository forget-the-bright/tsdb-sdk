# GE Historian 生产环境只读集成测试

本文说明如何对真实 GE Proficy Historian 执行集成测试，验证**原生 API**与**公共 API**
的请求、认证、时间格式、质量码与返回模型是否和现场一致。

## 1. 原则

- **只读**：测试只调用查询类端点，不创建、不删除、不改配置、不启停采集器、不恢复告警备份。
- **显式开启**：默认 `mvn test` 不执行；只有 `-Dge.it=true` 且提供凭据时才连接现场。
- **凭据不入库**：使用环境变量或被 `.gitignore` 排除的 `ge-it.properties`。
- **失败可诊断**：认证、TLS、超时分别映射为 `TsdbAuthenticationException`、
  `TsdbConnectionException`、`TsdbTimeoutException`。

## 2. 配置凭据

复制示例文件：

```powershell
Copy-Item tsdb-sdk-ge\ge-it.properties.example tsdb-sdk-ge\ge-it.properties
```

填写现场**只读账号**：

```properties
baseUrl=https://172.16.176.9
username=your-readonly-user
password=your-password
clientId=your-oauth-client-id
clientSecret=your-oauth-client-secret
# 或者只填现成 token：
# token=...
```

也可以用环境变量（优先级高于文件）：

```powershell
$env:GE_IT_USERNAME="your-readonly-user"
$env:GE_IT_PASSWORD="your-password"
$env:GE_IT_CLIENT_ID="your-oauth-client-id"
$env:GE_IT_CLIENT_SECRET="your-oauth-client-secret"
```

`ge-it.properties` 已在 `.gitignore` 中排除，不会上传 GitHub。

## 3. 自签名证书

现场证书为自签名，且 CN 通常是机器名（如 `JXTY-176-9`）而不是访问 IP，因此测试配置默认：

```properties
trustAll=true
verifyHostname=false
```

这两个开关只对当前实例生效。`trustAll` 打开时 `GeHttpClient` 会打印 WARN；正式长期接入应把现场根证书导入 JVM 信任库，或使用受信 HTTPS 反向代理，然后关闭这两个开关。

## 3.1 时间格式

铜陵现场 GE 的请求参数和响应时间都是 UTC，而界面通常要 GMT+8。测试配置支持三组开关：

```properties
requestEnabled=true
requestZone=UTC
requestPattern=yyyy-MM-dd'T'HH:mm:ssXXX
responseEnabled=true
responseSourceZone=UTC
responseTargetZone=GMT+8
responsePattern=yyyy-MM-dd HH:mm:ss
```

- `requestZone/requestPattern`：把 `Instant` 转成 GE 要的请求字符串；
- `responseSourceZone`：GE 返回文本没有时区时，按这个时区解释成绝对时刻；
- `responseTargetZone/responsePattern`：展示用，`GeClient.formatTimestamp(...)` 按它输出；
- 返回的 `Sample` 同时带 `timestampDate` 和 `timestampText`（按 `responseTargetZone/responsePattern` 生成），前端直接展示 `timestampText` 即可；
- 如果某个项目 GE 本身就用 GMT+8，把 `requestZone` 和 `responseSourceZone` 改成 `GMT+8` 即可，不需要改代码。
- **生产裁决（2026-11-12）**：`GeComparisonIT` 时间专项 A(旧 SDK) vs B(新 SDK 真 UTC) 逐点 MATCH，证实旧 SDK 输出的是**真 UTC**（其 hutool `DatePattern.UTC_FORMAT` 是绑定 UTC 的格式化器，与 JVM 默认时区无关），故新 SDK 默认 `requestZone=UTC / responseSourceZone=UTC` 即与现场一致；伪 UTC（GMT+8 墙钟 + 字面 `Z`）出现可复现 **+8h** 错位，已从预设中删除。

> 公共 API 的 `Sample.timestamp` 始终是 `Instant`，时区转换只发生在请求格式化和展示层。

## 4. 运行

只运行本集成测试（避免其他模块的 `-Dtest` 过滤报“没有测试”）：

```powershell
mvn -q -pl tsdb-sdk-ge -am test `
  "-Dtest=GeProductionIT" `
  "-DfailIfNoTests=false" `
  "-Dge.it=true"
```

> PowerShell 中带点的 `-D` 参数建议加引号，否则可能被拆成两个参数。

不传 `-Dge.it=true` 时，测试类会被 JUnit `Assumptions` 跳过，常规 `mvn test` 不受影响。

## 5. 覆盖范围

| 测试方法 | 验证内容 | 主要端点/公共 API |
|---|---|---|
| `healthAndCapabilities` | 认证、健康检查、能力声明、只读语义 | `GeClient.health()`、`capabilities()`、`writeSession()` |
| `browsesRealTagCatalog` | 标签目录与单标签查询 | `GET /v1/tags`、`GET /v1/tags/{nameMask}/{maxNumber}` |
| `readsRealCurrentValue` | 当前值、时间、质量、缺失值 | 公共 `currentValues().read()` → POST `/v1/datapoints/sampled`（samplingMode=1） |
| `readsRealRawHistory` | 原始历史、方向、条数、截断 | 公共 `history(RAW)` → POST `/v1/datapoints/raw` |
| `readsRealAggregatedHistory` | AVG 聚合、区间、interval | 公共 `history(AGGREGATED)` → POST `/v1/datapoints/calculated` |
| `readsRealInterpolatedHistory` | 插值历史 | 公共 `history(INTERPOLATED)` → POST `/v1/datapoints/interpolated` |
| `readsRealSampledHistoryAndCumulativeDelta` | 等间隔与累计差分 | 公共 `history(SAMPLED)` → POST `/v1/datapoints/sampled`（samplingMode=2）；差分用 `calculated` LastRawValue=19，起点前移一个间隔、服务端 `count = 窗口桶数 + 1`，第 0 桶即基线（缺桶才补一次批量 POST `raw`） |
| `invokesNativeTagAndDataEndpoints` | 原生 `GeEndpoint` + `invoke` 的 query/path 调用 | `QUERY_TAGS_BY_PARAMS`、`GET_CURRENT_VALUE_BY_PATH_VARIABLE`、`GET_RAW_DATA_BY_PATH_VARIABLE`、`GET_TAG_PROPERTIES_PATH` |
| `invokesNativeReadOnlySystemsCollectorsAndAlarms` | 系统、采集器、告警查询 | `GET_SERVER_PROPERTIES`、`GET_DATA_STORES`、`COLLECTOR_DETAILS`、`OFFLINE_COLLECTORS`、`QUERY_ALARMS` |
| `unwrapsNativeApi` | 原生逃生口 | `client.unwrap(GeNativeApi.class)` |

> 公共数据读路径本轮已从 GET 改 POST（大批量位号不再受 URL 长度限制）；GET 变体作为原生逃生口保留，由 `invokesNative*` 用例覆盖。

> 测试会优先使用 `ge-it.properties` 中的 `tag`；未指定时取标签目录第一条，并用其当前值时间作为历史查询锚点。

## 6. 现场验证记录（2026-11-09）

- `172.16.176.9:443` TCP 可达；`:80` 不可达，必须使用 HTTPS。
- 参照工程里的默认管理员账号请求 `/uaa/oauth/token` 返回
  **HTTP 401 `Bad credentials`**，不能直接用于该生产环境（为避免扩散凭据，此处不记录密码）。
- 使用参照工程测试类中的只读账号（`tjxcl_ro`）可以成功换取 Bearer token
  （`expires_in=43199`），说明现场 OAuth 与 Basic 客户端凭据正常。
- 现场证书为自签名（`subject=CN = JXTY-176-9`，签发者 `JXTY-176-9 Root CA 202502271211`），
  `curl` 默认校验报 `SEC_E_UNTRUSTED_ROOT`；测试用 `trustAll=true` + `verifyHostname=false` 联调。
- **实际执行结果：`Tests run: 10, Failures: 0, Errors: 0, Skipped: 0`，BUILD SUCCESS**（约 6.1 秒）。
  新增的 `readsRealSampledHistoryAndCumulativeDelta` 验证了 1 小时等间隔与累计差分；
  公共 API 的标签、当前值、RAW、AVG 聚合、插值历史与原生 `GeEndpoint` 的
  tags/currentvalue/raw/tag-properties、systems、collectors、alarms 查询均返回成功；
  当前值、RAW、AVG、插值均断言了非空样本，避免“请求成功但没有数据”的假通过。
- 现场 `GET /v1/tags` 即使命中结果也会返回 `ErrorCode=11`（`Refine Search Results.`）；
  `GeNativeApi` 已按“有 `Tags`/`Data` 载荷即视为成功”处理，避免把截断提示误判为失败。
- 常规 `mvn -pl tsdb-sdk-ge -am test` 仍为 22 个 Mock 测试全绿；生产 IT 不计入日常构建。

## 6.1 新旧一致性对比裁决（2026-11-12）

`GeComparisonIT` 以 **test scope** 引入旧 `GE_REST_SDK`，对同一位号、同一时间窗把**旧 SDK 与新 SDK 逐点比对**（时间戳 / 值 / 质量码 / 工程单位 / per-tag ErrorCode）。最近一次生产运行：

```text
[SUMMARY] MATCH=2021  DIFF=0  OLD_ONLY=0  NEW_ONLY=0  PROBE=481
```

- **主契约全 MATCH**（9 个场景）：7 种聚合（含 `SUM→9`）、sampled/interpolated/raw（各 24–50 点）、
  当前值（真标签逐字节一致，缺失位号 `n=0`）、interval-sum（`_SUM=4476.2542`、`_PV=-1.29551125`）、
  标签目录（`ErrorCode=11`）、时间 A(旧) vs B(新真 UTC)。
- **2000 tag 批量**：两侧单请求 POST 全成功（matched=2001，differed=0；new 4125ms / old 4412ms）；
  GET 对照返回 **HTTP 414**（URL 超长），记录为“必须改 POST”的证据。
- **469 个批量漂移标签**：经单标签紧挨复读证实为活数据在动（快更新电气测量块约 16s 归档周期），非 SDK 差异；
  稳定可复现的差异仍保留为 DIFF，不静默压制。
- **4 个 `verdict=DIFF` 全是反证探针**：伪 UTC +8h ×2、`SumValue 24` ≠ `17/19` 双请求 ×2，用于划定语义边界。
- 运行严格只读，凭据取 `ge-it.properties`（已 gitignore）不入库；复现命令见第 4 节（`-Dge.it=true`）。

> 结论：公共 API 与旧 SDK 查出的数据逐点一致，DIFF 归零；替换方案文档 `docs/13` 的映射据此落地。

## 7. 常见问题

**401 Bad credentials**：用户名/密码错误，或 OAuth client 无权限。先用 Postman/curl 单独验证
`/uaa/oauth/token`，确认 `grant_type=password` 与 Basic 客户端凭据都正确。

**证书错误**：确认 `trustAll=true`、`verifyHostname=false`；若现场改为受信证书，应关闭两者。

**读取超时**：大区间聚合查询可能超过 20 秒；调大 `readTimeoutMs`，或缩小时间范围。

**没有标签数据**：在 `ge-it.properties` 指定一个已知有数据的 `tag`；否则测试会按“无数据”跳过
依赖标签的用例。
